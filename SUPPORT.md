# Support

Aruo is currently in design phase and provides no production support or official binary. Questions and design discussions should use the repository’s public issue/discussion facilities once enabled. Bugs use the issue form; vulnerabilities and conduct concerns use the private paths in [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Before v0.1, this page will publish supported versions/platforms, response expectations, community versus commercial support boundaries, and links to troubleshooting and release status. No support commitment is implied before it is explicitly listed.
