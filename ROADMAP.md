# Roadmap

## Current stage

Aruo is pre-1.0. `aruo init` installs a managed AI engineering contract into an existing repository, `aruo doctor` audits that contract plus application intent and repository health, and the earlier `aruo create` catalog remains available as a secondary convenience. The next product milestone is safe managed-contract updates, not larger application templates. See [README.md](README.md) for exactly what works today.

## 0.1 — prove the model

- project/configuration schemas and deterministic repository plans;
- read-only `inspect` and `check` for Go and Python;
- human and stable JSON findings;
- conformance fixtures and performance/security baselines.

## 0.5 — safe repository operations

- create/adopt/fix/add and provenance-aware upgrade;
- Go, Python, Rust, TypeScript, CLI, service, React, and Vue profiles;
- signed first-party artifacts and cross-platform binaries;
- GitHub, documentation, and release adapters.

## 1.0 — dependable public contract

- stable CLI/config/plan/finding schemas;
- transactional mutation and tested recovery;
- out-of-process plugin protocol and SDK;
- reproducible signed releases, SBOMs, provenance, and migration policy.

## 2.0 — lifecycle platform

- organization policy packs and repository fleet inventory;
- migration campaigns and compatibility analysis;
- historical health evidence and optional hosted collaboration;
- mature ML/CV and governed benchmark profiles.

## 5.0 direction

Evidence-grounded architecture assistance, policy simulation, onboarding generated from verified facts, and a federated community artifact ecosystem.

## Explicitly deferred

Hosted accounts, public plugin marketplace, autonomous code changes, deployment-provider abstraction, IDE daemon, and AI-generated fixes are deferred until the local deterministic engine is trustworthy.

Milestones are capability gates, not date promises. See [the release process](docs/development/release.md) for release readiness.
