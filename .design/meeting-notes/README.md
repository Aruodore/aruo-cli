# Meeting notes

The complete decision history for this project is kept on one chronological page:

- [Aruo project journal](project-journal.md)

The journal should capture context, participants when known, evidence reviewed, decisions, unresolved questions, follow-ups, and links to resulting issues, RFCs, ADRs, or public contracts.

The journal is not a substitute for formal decisions. Promote consequential outcomes into an ADR, RFC decision, roadmap, or public contract. Correct factual errors transparently; do not rewrite history to remove disagreement.

Do not record secrets, vulnerability details, private personal information, confidential partner data, raw transcripts, or performance judgments about individuals. Obtain consent before attributing sensitive viewpoints.
