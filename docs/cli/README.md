# CLI reference

The normative interaction, signal, keyboard, prompt, progress, output,
accessibility, compatibility, and performance contract is the
[Terminal UX specification](terminal-ux.md). This page defines the
command surface; future commands must satisfy both documents.

Shell completion (bash, zsh, fish, PowerShell) is generated by Cobra today,
including dynamic completion for template/language/kind/format/color/motion
values; see the terminal UX specification's
[implementation status](terminal-ux.md#implementation-status-2026-08-06) for
what else is and is not implemented. Command syntax, flags, defaults,
environment variables, exit codes, and JSON schemas are not yet generated
from the command model and checked for drift; that remains future work.
Narrative troubleshooting remains hand-written.

## Implemented surface

The pre-0.1 implementation exposes `aruo`, `aruo help`, `aruo version`, `aruo create`, and the read-only repository health command `aruo doctor`. The broader model below remains a design target. See [CLI Application Architecture](../architecture/cli-application.md), [Create Command Architecture](../architecture/create-command.md), and [Repository Doctor Architecture](../architecture/doctor.md).

### Create

Interactive:

```sh
aruo create
```

Non-interactive:

```sh
aruo create ./my-library \
  --template go-library \
  --module example.com/my-library \
  --description "A production-quality Go library." \
  --author "Example Authors" \
  --no-input
```

Use `--language` and `--kind` to filter catalog entries, `--set key=value` for declared template variables, and `--yes` to accept interactive confirmation. Creation refuses every existing destination.

### Doctor

```sh
aruo doctor .
aruo doctor . --format json --minimum-score 90
```

Doctor performs local, offline, read-only checks. It scores completeness, documentation, CI, tests, license, security, and GitHub configuration under versioned policy `aruo.repository-health/v1`. Scores below `--minimum-score` return findings exit code 3 after printing the complete report.

## Proposed command model

```text
aruo create|adopt|inspect|check|fix|plan|upgrade
aruo add|remove|run
aruo release plan|prepare|verify
aruo publish
aruo migrate plan|apply
aruo template ...
aruo plugin ...
aruo config get|set|explain|validate
aruo doctor
aruo completion
```

`doctor` now owns the initial broad repository-health assessment. A future `check` command may enforce selected organization policies, while environment diagnosis will require an explicit doctor mode. Documentation, tests, lint, and benchmarks are normalized tasks under `run`. `release` changes local/repository state; `publish` makes an explicit external change.

## Proposed global behavior

Global flags include `--cwd`, `--config`, `--profile`, `--format human|json|sarif`, `--color auto|always|never`, `--quiet`, `--verbose`, `--offline`, `--yes`, and `--no-input`. Flags override purpose-built environment variables, which override files. `NO_COLOR`, redirected output, dumb terminals, reduced motion, and CI are respected.

Human results go to stdout; diagnostics/progress to stderr. JSON is versioned, undecorated, and stable. Exit codes: `0` success/conformant, `1` operational failure, `2` usage/configuration, `3` findings at threshold, `4` unresolved conflicts, `5` trust/security refusal.

## Interaction

Interactive prompts ask only consequential questions, show recommended choices with implications, support back/review, and end with a plan. Non-interactive mode never invents missing identity, license, or publish targets. `--yes` approves only a deterministic displayed/saved plan.

Spinners appear only for indeterminate TTY work; stable step counts show determinate progress. Color and icons never carry meaning alone. Help is task-oriented, shows defaults/source, examples, related commands, and external-effect warnings. Completions support bash, zsh, fish, and PowerShell from the same command model.

Errors contain summary, cause, evidence/location, safe recovery, and debug reference. Stack traces are opt-in. Destructive or external effects name their exact target and support dry-run where meaningful.
