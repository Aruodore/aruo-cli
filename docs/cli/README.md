# CLI reference

The [Terminal UX specification](terminal-ux.md) is the normative implementation
guide for process lifecycle, keyboard behavior, prompts, progress, output,
terminal compatibility, errors, accessibility, performance, and testing.

The normative experience contract is [CLI.md](../../CLI.md). Once implementation begins, command syntax, flags, defaults, environment variables, exit codes, JSON schemas, examples, and completions will be generated from the command model and checked for drift. Narrative troubleshooting remains hand-written.
