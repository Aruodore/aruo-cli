# CLI reference

The [Terminal UX specification](terminal-ux.md) is the normative implementation
guide for process lifecycle, keyboard behavior, prompts, progress, output,
terminal compatibility, errors, accessibility, performance, and testing.

The normative experience contract is [CLI.md](../../CLI.md). Shell completion (bash, zsh, fish, PowerShell) is generated by Cobra today, including dynamic completion for template/language/kind/format/color/motion values; see the terminal UX specification's [implementation status](terminal-ux.md#implementation-status-2026-08-06) for what else is and is not implemented. Command syntax, flags, defaults, environment variables, exit codes, and JSON schemas are not yet generated from the command model and checked for drift; that remains future work. Narrative troubleshooting remains hand-written.
