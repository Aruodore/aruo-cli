# Frequently asked questions

## Is Aruo another project generator?

No. Creation is one workflow in a repository lifecycle control plane.

## Does Aruo replace language tools?

No. It delegates builds, tests, formatting, dependencies, and publishing to native tools.

## Does Aruo require cloud or AI access?

No. Core workflows are local-first and offline-capable.

## Is Aruo ready to install?

No. The project is in design phase and has not published an official binary.

## Why Go?

Portable binaries, fast startup/builds, simple concurrency, mature CLI tooling, and a comparatively approachable maintenance model. See ADR-0002.
