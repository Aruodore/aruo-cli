# Benchmarks

Published benchmarks follow [PERFORMANCE.md](../../PERFORMANCE.md). Each report identifies workload and data, commit/version, hardware/software, cold/warm state, sample count, statistics, allocations/memory, raw results, reproduction command, and limitations. Comparative claims require equivalent setups. Raw results and immutable reports belong under [`benchmarks/results/`](../../benchmarks/README.md), not this narrative section.
