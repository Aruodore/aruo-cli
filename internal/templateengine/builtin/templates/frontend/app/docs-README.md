# Documentation

This is a production-baseline browser application, not a backend. The repository guarantees a strict, tested, reproducible frontend build. It does not claim authentication, server authorization, API correctness, deployment safety, monitoring, or recovery.

Before serving traffic, select a deployment platform, define immutable asset caching and rollback, configure TLS and security headers at the edge, validate every external API contract, test accessibility and critical browser journeys, and establish error monitoring with an intentional privacy policy.

`AGENTS.md` is the development contract. `aruo.yaml` records which concerns are solved, required, optional, deferred, or unknown.
