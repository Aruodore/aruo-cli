# Documentation

This repository provides a strict, tested Next.js production baseline. It intentionally does not choose identity, authorization policy, database, deployment platform, rate limiting, telemetry provider, or backup strategy before the application requires them.

Read `AGENTS.md` for architectural rules. Read `aruo.yaml` for the explicit SOLVED, REQUIRED, OPTIONAL, DEFERRED, and UNKNOWN capability record. Update both when the application gains a production concern.
