# Contributing

Thank you for contributing.

1. Discuss substantial changes in an issue before implementation.
2. Create a focused branch and follow Conventional Commits.
3. Add or update tests and documentation with behavior changes.
4. Run `make check` locally.
5. Open a pull request explaining intent, tradeoffs, verification, and risk.

Pull requests require passing CI and review. Keep changes small, preserve compatibility, and never include secrets or generated build artifacts.
